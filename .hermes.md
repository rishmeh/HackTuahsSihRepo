## What This Repo Is

**Table Tot** — an AI-powered desk companion robot for students. Smart India Hackathon 2026, Problem Statement SIH26224 (Student Innovation), Theme: Smart Education, Category: Hardware. Team: HackTuah.

The robot lives on a student's study desk, learns their routine, and builds personalised productivity workflows. Raspberry Pi 5 with camera, mic, speaker, servos, animated face, PIR sensor. Offline-first AI with on-device SLM (Qwen via llama.cpp), Moonshine STT, Kokoro TTS. Parent dashboard is a React + Vite web app over local WiFi.
